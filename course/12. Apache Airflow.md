# Definition
* Apache Airflow is an open-source workflow orchestration platform created by Airbnb and now part of the Apache Software Foundation.
* It’s widely used for authoring, scheduling, and monitoring data pipelines

# What Is Apache Airflow?
* Airflow lets you define workflows as Directed Acyclic Graphs (DAGs) using standard Python code.
* Each step in your pipeline is called a task, and Airflow handles the execution and dependencies between them
